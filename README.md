# 今晚你跑不掉 🦟

> Tonight You Can't Escape — 模擬真實打蚊子體驗的休閒舒壓 Web 遊戲

核心情緒弧線：**煩躁累積 → 緊張瞄準 → 爽快釋放**

## 玩法

- 🖐 **徒手**：要靠很近、靠近後手掌會放大遮住視線，盲打感
- 🪰 **打蚊拍**：中距離可揮、需對準蚊子方向
- ⚡ **電蚊拍**：放下後保持靜止，蚊子飛過拍面自動觸殺

包包累積到 **8 個** = Game Over。

## 開始遊戲

直接打開 `index.html` 即可，無需任何 build 步驟。建議戴耳機，立體聲嗡嗡聲定位是核心玩法之一。

```bash
# 本機開啟
open index.html

# 或啟動簡易 server
python3 -m http.server 8000
```

## 技術

- 純前端：HTML + CSS + Canvas + Web Audio API
- 蚊子嗡嗡聲為即時合成（3 層諧波 + vibrato + 帶通整形）
- 環境音、心跳緊張音樂、命中音效全部即時合成
- 零依賴、零 build step
